## Фаза 1 — баги, що псують прогрес (≈ 2–3 год)

Кожен пункт — окремий маленький коміт. Перевірка — через `tools/engine.js` або Playwright.

| # | Що | Де (якір) | Правка | Як перевірити |
|---|---|---|---|---|
| 1.1 | Подвійний тап під час вильоту картки: бокс +2, наступна картка пропущена | `function flyOut`, `function armSwipe`, `function bindQuit` | На вході в `flyOut`: якщо картка вже летить — `return`; одразу `disabled` на `#actL` / `#actR`. У `setTimeout` перевіряти, що сесія та сама (`const sess = S; … if (S !== sess) return;`) — це ж лікує ✕ під час вильоту | Playwright: `page.dblclick('#actL')` на картці вивчення → лічильник `.sessbar .n` зріс рівно на 1 |
| 1.2 | Імпорт без перевірки: `null` ламає застосунок, `{}` стирає прогрес | `document.getElementById("impf").onchange` у `renderProg` | Приймати лише звичайний об'єкт; брати тільки ключі, що є в `BY_ID`; значення — об'єкт із числовим `b` 0–5 і `due`; решту полів доповнювати (`l:0, s:0`). 0 валідних → повідомлення, нічого не міняти. Інакше `confirm("Zastąpić obecny postęp? W pliku: N pojęć.")`. Після імпорту й скидання — `S = null` і перемалювати Ćwicz | stand: імпорт `null`, `{}`, `[]`, `{"A-01":{"b":2}}`, чужий JSON |
| 1.3 | «Słabe punkty» ніколи не заповнюються | `function bump`, `function renderProg` | За D4: у гілці помилки `s.l = (s.l||0) + 1`. Оновити коментар про «мертве поле» в коді, `CLAUDE.md` і `docs/learn-mode-v2.md` | stand: двічі `bump(e,false)` → `st(e.id).l === 2` |

| 1.6 | «tooltip. » і `przedrostek/przyrostek` не зараховуються | `const norm`, `function accepted`, `function typeMode` | Порядок у `norm`: lower → `normalize("NFC")` → зняти діакритику → схлопнути пробіли й trim → зняти кінцеві `.,;:!?` → trim. Пробіли навколо `/` необов'язкові. Enter під час IME (`ev.isComposing`) ігнорувати; порожня відповідь не з'їдає спробу; на останній спробі червоний стан не знімати | stand: `"tooltip. "`, `"Tooltip"`, `"światło międzyliterowe".normalize("NFD")`, `"przedrostek/przyrostek"`, `"  przedrostek  "` → усі `true`; `""` → не мінус спроба |
| 1.7 | Підказка по літері до кінця слова = повний бал | `function typeMode` | За D5: якщо `hinted >= Math.ceil(e.pl.length / 2)`, правильна відповідь веде на `reveal(e, false)` з поясненням «Z podpowiedzią — wrócimy do tego» | Playwright: 5× «Podpowiedz literę» + ✓ → бокс не виріс |

Правила для кожного запису:

1. Поля: `c, n, en, alt, pl, ua, o:{pl,en}, ex:{ua,pl,en}, d`; `note` + `nt:{pl,en}` — лише разом.
2. `ua` — 1–3 речення, переказ визначення з джерела. **Жодних вигаданих термінів, значень чи назв токенів** — тільки те, що є в `research-02-sources` зі статусом ✅ або ⚠️ (⚠️ позначати в `note`).
3. `pl` — тільки з `*-pl.md`. Якщо офіційного немає — D2.
4. `ex` — **одна** фраза, як термін звучить у робочій розмові, на матеріалі дистрибуції електроніки (MOQ, BOM, ceny progowe, stan magazynowy). Показує, що поляки кажуть польською, а що лишають англійською.
5. Польські тексти: лапки „ ”, вкладені « »; `&nbsp;` після однолітерних слів (i, a, o, u, w, z).
6. Демо: HTML/CSS, без картинок; **без польської відповіді в тексті демо** (`check-data.js` попередить); класи демо без префікса `l-`; `:hover` у демо дозволений. Використовувати наявні демо-класи (`.row`, `.col`, `.b`, `.b-p` …) — вони в CSS-блоках `DEMO PRIMITIVES`, `K · SPACING DEMOS`, `L · TYPOGRAPHY DEMOS`. Нові стилі для демо M додавати окремим блоком `M · TOKEN DEMOS` поруч з ними.

## Правила проєкту, які легко порушити

- Класи UI застосунку — тільки з префіксом `l-`.
- `:hover` на кнопках застосунку — тільки всередині `@media (hover:hover) and (pointer:fine)`, для дотику — `:active`.
- Не повертати скасовані рішення v1: одна кнопка «Ćwicz» без режимів і відмова від друкування відповіді.
- Не додавати: matching-гру, streak-и, таймери, повний SM-2, змішаний режим.
- EN назва, PL термін і демо не перемикаються мовою. Перемикач EN·PL·UA міняє лише пояснення, `note` і фразу.
- PR створювати тільки на прохання користувача.
