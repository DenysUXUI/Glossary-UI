# Дизайн-система Katalog UI · v3

Стиль «спокійний продуктовий»: світлі площини з м'якою тінню замість рамок, IBM Plex Sans у тексті інтерфейсу, mono тільки для кодів і ідентифікаторів, PCB-зелений як єдиний акцент. Тільки світла тема. Навігація — таб-бар знизу.

Джерело правди — `:root` в `index.html` (блок `ДИЗАЙН-СИСТЕМА v3 · ТОКЕНИ`). Цей документ описує правила, а значення беруться з коду.

Передісторія: `docs/audit-03-design-system.md` (аудит v2, 40/100) → три варіанти стилю → обрано варіант A.

## Правила

1. **Компоненти застосунку беруть значення тільки з токенів.** Нових hex, px-розмірів шрифту чи тривалостей у компонентах немає. Виняток — геометрія, яка не повторюється (ширина колонки назви в прогресі, розмір іконки).
2. **Один компонент на роль.** Перш ніж додати клас, перевір таблицю компонентів нижче.
3. **Префікс `l-`** для кожного класу застосунку (причина в CLAUDE.md, баг із `.done`).
4. **Демо в `DATA` живуть на окремій палітрі** (`--ink`, `--line`, `--pcb`, `--r` …). Інтерфейс застосунку її не використовує, а демо не використовують токени застосунку. Редизайн застосунку не змінює вигляд демо.
5. **Hover тільки в `@media (hover:hover) and (pointer:fine)`**, для дотику є `:active` (sticky hover на iOS).
6. **Глибина дається тінню й фоном.** Рамка лишається там, де вона несе зміст: межа поля вводу, вимкнений режим (пунктир), роздільники в списках.

### Типографіка

IBM Plex Sans для тексту, IBM Plex Mono для кодів (`A·01`), синонімів (`btn`) і номерів секцій. Ваги: 400, 500, 600.

| Токен | Розмір | Де |
|---|---|---|
| `--fs-micro` | 11 | підпис таб-бару, мітка PL, тег |
| `--fs-caption` | 12 | коди, мета, підписи блоків |
| `--fs-small` | 13 | другорядний текст, пігулки, підказки |
| `--fs-body` | 15 | основний текст |
| `--fs-lead` | 16 | назви рядків, опис у навчанні, поля вводу (менше 16 — iOS збільшує сторінку) |
| `--fs-title` | 20 | назва запису, секції, підекрану |
| `--fs-display` | 28 | заголовок екрана, термін у навчанні |

Міжрядковий інтервал: `--lh-tight` 1.2 (заголовки) · `--lh-ui` 1.4 (рядки інтерфейсу) · `--lh-read` 1.55 (текст для читання).

## Компоненти

### Кнопка · `.l-btn`

- **Призначення:** будь-яка дія. Одна кнопка на всі ролі замість восьми реалізацій v2.
- **Слоти:** іконка `.l-i` (опц.) + текст.
- **Варіанти:** `--primary` (головна дія, на екрані одна) · `--secondary` (рівноправна альтернатива) · `--ghost` (дія в шапці: «Gotowe») · `--danger` (руйнівна: «Zresetuj»).
- **Розміри:** md 48 px (за замовчуванням) · `--sm` 36 px (інструменти в «Postęp»). Модифікатор `--block` розтягує на всю ширину.
- **Стани:** default · hover (тільки миша) · active · focus-visible (обвідка 2 px `--accent`) · disabled (`--surface-muted`, текст `--text-2`).
- **Доступність:** справжній `<button>`. Кнопка тільки з іконкою отримує `aria-label` (`#chk` «Sprawdź»).
- **Приклад:** `<button class="l-btn l-btn--primary l-btn--block" id="again">Jeszcze pięć pojęć</button>`

### Рядок · `.l-row`

- **Призначення:** кнопка-картка зі вмістом: режим навчання, вхід у вибір категорій.
- **Слоти:** `.l-ico` (44 px; `--solid` для головного режиму, `--sm` 36 px) · `.l-row-txt` (`<b>` назва + `<small>` підпис) · `.l-num` (лічильник) або `.l-chev`.
- **Стани:** default (тінь `--sh-1`) · hover (`--sh-2`) · active (`--surface-sunken`) · disabled (прозорий фон, пунктир, усе `--text-2`; підпис лишається читабельним, бо пояснює, коли режим відкриється).
- **Приклад:** `<button class="l-row l-mode" id="m-new"><span class="l-ico l-ico--solid">…</span><span class="l-row-txt"><b>Nowe pojęcia</b><small>…</small></span><span class="l-num">5</span></button>`

### Картка · `.l-card`

Біла площина, `--r-lg`, `--sh-1`. З `.l-list` стає контейнером списку з роздільниками (вибір категорій, прогрес, слабкі місця). Навчальна картка `.l-qcard` — той самий компонент з `--sh-2`.

### Тег · `.l-tag`

- **Призначення:** тип картки («Nowe pojęcie»), стан запису («Nowe», «Znam»).
- **Варіанти:** нейтральний · `--accent` · `--dot` + `.l-lv0…3` (крапка кольору рівня; сам текст лишається `--text-2`, тож колір не єдиний носій сенсу).

### Поле вводу · `.l-field`

- **Призначення:** пошук у каталозі, набір PL-терміна.
- **Стани:** default (межа `--border-strong`, 3.3:1) · focus (межа + кільце `--accent`) · `.ok` · `.no` · disabled.
- **Доступність:** 16 px (без автозуму iOS), `aria-label`, бо видимої мітки немає.

### Сегмент-контрол мови · `.l-lang`

- **Призначення:** EN · PL · UA для опису. Контрол стоїть у кожній картці, стан глобальний (`setLang`, `localStorage` `katalog-ui-lang`).
- **Стани:** вибраний — білий бігунок із `--sh-thumb`.
- **Доступність:** `role="group"` + `aria-label`, кнопки з `aria-pressed`. Зона дотику 32×28 (WCAG 2.2 AA вимагає 24×24).

### PL термін · `.l-pl`

Кнопка `PL` + термін, тап копіює в буфер (тост «skopiowano»). `aria-label="PL przycisk, skopiuj"` — назва починається з видимого тексту (WCAG 2.5.3).

### Пігулка категорії · `.l-chip`

- **Призначення:** перехід до секції каталогу, scroll-spy підсвічує поточну.
- **Слоти:** назва + лічильник `<span>`.
- **Стани:** default · `.on` (акцент) · `.l-off` (секції немає після пошуку).
- **Адаптивність:** горизонтальний скрол без смуги, виходить за поля екрана.

### Прогрес-бар · `.l-progress` / `.l-bar`

`.l-progress` — сесія (`role="progressbar"` з `aria-valuenow`). `.l-bar` — розбивка категорії на рівні (`role="img"` з текстовим описом).

### Таб-бар · `.l-tabbar`

- **Призначення:** Ćwicz · Katalog · Postęp, під великим пальцем.
- **Стани:** вибраний — `--accent` + вага 600 + `aria-current="page"`.
- **Адаптивність:** висота 64 + safe area iOS (`viewport-fit=cover`), на широкому екрані пункти стоять у колонці 480 px по центру.

### Лунка · `.l-well` / `.l-stage`

Демо на крапковій сітці — впізнаваний прийом каталогу. `.l-well` — нижня частина запису (на ≥ 820 px праворуч), `.l-stage` — у навчальній картці, з радіусом і відступом.

## Відомі обмеження

- **Заливки рівнів у смужці категорії** (`--lv-1-fill`, `--lv-2-fill`) мають 1.6–2.2:1 з доріжкою. Кількість «Znam + Opanowane» подана текстом поруч, повна розбивка є в плитках угорі та в `aria-label` смужки. Щоб заливки дотягнули до 3:1, їх довелося б зробити однаково темними, і рівні перестали б розрізнятися за світлотою.
- **Зони дотику 28–34 px** у сегменті мови, пігулках і PL-терміні. Мінімум WCAG 2.2 AA (24×24) виконано, рекомендацію Apple HIG (44×44) — ні: картка каталогу щільна.
- **PDF-каталог** (`docs/katalog-ui-glosariusz.pdf`) зібраний зі старих стилів друку. Його треба перезібрати з нових (`@media print`).
