# Handoff — Katalog UI

<handoff>

<context>
Проєкт: **Katalog UI** — тримовний глосарій елементів інтерфейсу (EN назва · PL переклад · UA пояснення) з живими візуальними прикладами, який переріс у навчальний застосунок зі spaced repetition.

Почалось як довідник термінології для роботи в польському середовищі: потрібно було знати, як елементи називаються офіційно польською і як їх реально називають у польських продуктових командах. У процесі виявилось, що просто переглядати список недостатньо — потрібен інструмент, який дає реально запам'ятати терміни, з видимим прогресом «що вже знаю, що треба підтягнути».

Стан на момент handoff: робоча версія зібрана, протестована end-to-end, готова до публікації на GitHub Pages. Розмова велась українською.
</context>

<decisions>

**Контент**
- Список елементів збирався з першоджерел, не з пам'яті: W3C ARIA APG (30 патернів), Apple HIG, shadcn/ui (68 компонентів), Material Design 3. Польська термінологія — з польських джерел, включно з верифікацією типографічних термінів.
- Разом **160 записів у 12 категоріях**: A Дії · B Поля вводу · C Вибір · D Навігація · E Контейнери · F Оверлеї · G Статус і фідбек · H Контент і дані · I E-commerce · J Стани й анатомія · K Відступи й сітка · L Типографіка.
- Кожен запис має живе демо на HTML/CSS, а не картинку.
- Приклади й копірайт побудовані на матеріалі дистрибуції електроніки (MOQ, ceny progowe, BOM, stan magazynowy) — щоб секція E-commerce одночасно була словником предметної області.
- Подається два шари термінології: офіційний польський термін + позначка, коли в мовленні команди використовують англійське слово. Причина: у польських продуктових командах домінує англійська, «чистий» переклад звучав би як переклад ГОСТу.

**Навчальна механіка**
- Відхилено меню з режимами на вибір. Замість цього одна кнопка «Ćwicz» — система сама вирішує, що показати. Логіка Anki, не Quizlet.
- Leitner, 5 боксів, інтервали 0 / 2 / 7 / 21 / 60 днів. Помилка скидає в бокс 1, не на крок назад.
- Тип картки залежить від рівня засвоєння: 0 знайомство → 1 демо→назва (4 варіанти) → 2 назва→демо → 3 вільне пригадування з самооцінкою → 4 EN→PL → 5 розрізнення схожих.
- 27 кураторських пар для рівня 5 (margin↔padding↔gap, leading↔tracking↔kerning, tooltip↔popover↔hover card, select↔combobox↔autocomplete тощо).
- Інтерлівінг: сусідні картки в сесії не з однієї категорії.
- Сесія — 12 карток.
- Викинуто свідомо: matching-гра, друкування відповіді, streak-и й таймери, повний алгоритм SM-2.

**Технічні**
- Прогрес у `localStorage`, ключ `katalog-ui-v1`. Плюс експорт/імпорт JSON як страховка.
- Хостинг — GitHub Pages. Причина: `localStorage` у локальному файлі ненадійний, на iOS злітає.
- Раніше зʼясувалось, що QuickLook на iOS не виконує JavaScript — тому окремо існує PDF-версія для читання офлайн.

</decisions>

<key_details>

**Файли**
- `index.html` — застосунок, ~174 KB, один самодостатній файл. Назва критична для GitHub Pages.
- `katalog-ui-glosariusz.pdf` — 67 сторінок, тільки каталог, для офлайн-читання.
- `README-github-pages.md` — інструкція публікації, 4 кроки без термінала.

**Структура коду в `index.html`**
- `DATA` — масив з 160 записів. Поля: `c` категорія, `n` номер, `en`, `alt`, `pl`, `ua`, `note` (опційно), `d` HTML демо.
- `CATS` — назви категорій (UA + PL).
- `PAIRS` — масив масивів з id для карток розрізнення.
- `INTERVAL` — інтервали Leitner.
- Класи навчального інтерфейсу мають префікс `l-` (`.l-opt`, `.l-optdemo`, `.l-done`, `.l-grade`). Це зроблено після реального бага: клас `.done` конфліктував з демо степера і обривав сесію. **Будь-які нові класи UI застосунку теж мають бути з префіксом `l-`.**

**Дизайн**
- Палітра: PCB-зелений `#0B5C43`, латунь `#8A6516`, папір `#ECEEEA`, чорнило `#14181A`.
- Шрифти: IBM Plex Sans + IBM Plex Mono (обидва мають кирилицю й польські діакритики).
- Демо-приклади сидять у «лунці» з крапковою сіткою.

**Знахідки, які варто памʼятати**
- `L-12 Sierota / wiszący spójnik` — польське правило: односимвольні слова (i, a, o, w, z) не можна лишати в кінці рядка, `&nbsp;` після них. Помітно для польського користувача.
- `L-14 Cyfry tabelaryczne` — `font-variant-numeric: tabular-nums`, дешеве покращення B2B-таблиць з цінами.
- `wdowa` / `bękart` / `szewc` — жаргон, визначення розходяться між польськими джерелами. У записі це позначено явно.

</key_details>
