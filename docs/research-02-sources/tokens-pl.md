## Notes for the editor

- **Nothing in tiers 1–2** (token, primitive, semantic, component, alias as a tier, DTCG) is localised by any vendor read. In Polish product teams the English words are the working terms; this table says only that no official PL string exists in this corpus.
- **Density** is the one design-system word with a clean official PL pair: Firefox `Density` → `Gęstość i upakowanie`, with `Compact` → `Zwarte`, `Standard` → `Standardowe`, `Touch` → `Dotykowe` (customizeMode.ftl:9, :24–28 and preferences.ftl:2093–2118, EN preferences.ftl:2446–2474). Android prefers a different phrase (`display density` → `układ interfejsu`, strings.xml pl:4250).
- **Opacity** is the trap: Polish vendors split between `nieprzezroczystość` and `przezroczystość`. Pick one deliberately; both exist in official UIs.
- **Primary / secondary** are translated, but only for non-colour things (axes, icons, sidebars). Do not read them as colour-role names.
- **Success** has two Microsoft renderings (`Sukces`, `Powodzenie`); LO uses `Sukces`.
- Calc cell styles in LibreOffice are the only place a vendor ships a status-colour set with PL names: Good = Dobry, Neutral = Neutralny, Bad = Zły, Warning = Ostrzeżenie, Error = Błąd, Accent 1–3 = Akcent 1–3 (sc.po:1803–1851). LO's Impress theme editor adds Dark 1/2 = Ciemny 1/2, Light 1/2 = Jasny 1/2, Accent 1–6 = Akcent 1–6, Hyperlink = Hiperłącze (svx.po:21648–21714).
- Unit abbreviations stay Latin: `px`, `pt.` (LO adds a period), `cm`, `mm`. `cal` = inch, `cycero` = pica (LO sc.po:21059, 21077).
